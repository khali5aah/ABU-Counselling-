3) backend/apps/common/phone.py

- PHONE_ERROR_MESSAGE = "Enter a valid Nigerian mobile number, e.g. 08031234567."
- def normalize_ng_phone(raw: str) -> str implementing docs/api-contract.md §1.1 exactly: strip; remove characters " -().". If startswith "+234": candidate = raw. elif startswith "234": "+" + raw. elif startswith "0" and len == 11: "+234" + raw[1:]. elif len == 10 and isdigit: "+234" + raw. else invalid.
