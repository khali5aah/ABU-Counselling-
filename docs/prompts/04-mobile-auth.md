3) core/api/api_exception.dart
  class ApiException implements Exception { final int statusCode; final String code; final String message; final Map<String, List<String>> fields; final int? retryAfter; final int? attemptsRemaining; String? fieldError(String name) => fields[name]?.first; }
  factory ApiException.fromResponse(int status, String body): parse envelope {"error": {code, message, fields?, retry_after?, attempts_remaining?}}; if not parseable → code "server_error", message "Something went wrong. Please try again.".
  const networkError = code "network_error", message "Can't reach the server. Check your connection and try again.", statusCode 0.

4) core/storage/token_storage.dart
  abstract class TokenStorage { Future<String?> readAccess(); Future<String?> readRefresh(); Future<void> save({required String access, required String refresh}); Future<void> clear(); }
  class SecureTokenStorage implements TokenStorage — FlutterSecureStorage(aOptions: AndroidOptions(encryptedSharedPreferences: true)); keys "access_token", "refresh_token".
  class InMemoryTokenStorage implements TokenStorage — for tests ONLY. The running app (mock mode included) always uses SecureTokenStorage, so restart behaviour is realistic.

5) core/api/api_client.dart
  abstract class ApiClient {
    Future<OtpRequestResult> requestOtp(String phoneNumber);
    Future<OtpVerifyResult> verifyOtp({required String phoneNumber, required String requestId, required String code});
    Future<AuthSession> setupAccount({required String setupToken, required String username, required String password});   // saves tokens
    Future<AuthSession> login({required String username, required String password});                                       // saves tokens
    Future<User> me();                                                                                                        // auto-refresh once on 401
    Future<void> logout();                                                                                                    // never throws; always clears tokens
    Future<bool> hasSession();                                                                                                // refresh token present
  }

6) core/api/http_api_client.dart — HttpApiClient(TokenStorage storage, {http.Client? client})
  - Base URL Env.baseUrl. Headers on every request: Content-Type application/json, Accept application/json, ngrok-skip-browser-warning true; plus Authorization: Bearer <access> for me/logout.
  - Timeout 15 s. SocketException, TimeoutException, http.ClientException, HandshakeException → throw ApiException.networkError.
  - Non-2xx → throw ApiException.fromResponse.
  - Endpoints and bodies exactly as contract §3: POST /api/v1/auth/otp/request/ {phone_number}; POST /api/v1/auth/otp/verify/ {phone_number, request_id, code}; POST /api/v1/auth/setup-account/ {setup_token, username, password}; POST /api/v1/auth/login/ {username, password}; POST /api/v1/auth/refresh/ {refresh}; GET /api/v1/auth/me/; POST /api/v1/auth/logout/ {refresh}.
  - setupAccount/login: on success storage.save(access, refresh) before returning.
  - me(): send with access token; if response is 401 (code token_invalid or not_authenticated) → call _refresh() once and retry once. _refresh(): single-flight (share one Future if already running); reads refresh token; none → throw ApiException(401, "token_invalid", "Your session has expired. Please log in again."); POST refresh; 200 → storage.save(new access, new refresh); any failure → storage.clear() and rethrow as token_invalid.
  - logout(): if a refresh token exists, POST logout with Bearer access and {refresh}, ignoring any error; finally storage.clear().
